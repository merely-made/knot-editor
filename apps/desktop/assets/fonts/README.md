# Bundled font provenance

Unmodified font files and their full copyright/licence notices from
[google/fonts](https://github.com/google/fonts), pinned commit
`23e54b51ddffbc7713c583748e3bd86f62b1fa4a`.

IBM Plex Mono: `ofl/ibmplexmono`, regular, bold, italic and bold italic.
Source Serif 4: `ofl/sourceserif4`, upright and italic variable fonts
(`opsz,wght`). The filenames are shortened locally; the font binaries are not
modified. Native name/weight/style metadata drives host registration.

Both families retain their upstream SIL Open Font License 1.1 notices in
their directories. The desktop embeds the full notices and offers them through
Appearance; no font is fetched at application runtime in this slice.
